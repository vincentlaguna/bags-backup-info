# Bags Backup

Bags Backup is a private-use backup setup operated by Vincent Laguna.
It uses rclone to access an authorized Google Drive account and
restic to encrypt and maintain versioned backups.

This application is not offered as a public service.
This website contains information only, not backup data or credentials.
